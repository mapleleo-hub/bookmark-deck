## 1. 名称

```
Bookmark Deck
```

13 字符。不含 Chrome 字样（商店政策禁止在名称中使用 Google 商标作为独立词）。

## 2. 简短描述

```
新标签页书签管理：把浏览器书签做成图标网格，拖拽排版直接写回书签本体。支持文件夹层级、Ctrl+K 搜书签和标签、批量整理。一份数据，不用同步，不联网。
```

## 3. 详细描述

```
Bookmark Deck 把浏览器自带的书签变成一个新标签页。

打开新标签页，看到的是书签栏里的文件夹，一列排在左边，每个文件夹里的书签铺成图标网格。拖动图标可以换位置，也可以拖到别的分页，改完直接写回浏览器书签，在 Chrome 自带的书签管理器里看到的顺序也跟着变。

和常见的新标签页扩展相比，这里没有第二份数据。它们通常要把书签复制一份进自己的存储，于是得做两边同步。这里读写的始终是 chrome.bookmarks，不存在两边不一致的问题。

主要功能

- 分页映射：书签栏的一级文件夹就是左侧分页，改分页等于改文件夹，两边永远是同一份数据
- 拖拽整理：页内排序、拖到别的分页、拖到文件夹卡片上收进去、拖到面包屑上移出，都可以撤销
- 文件夹层级：子文件夹显示为卡片，点开继续下钻，层级不限深度，面包屑可逐级回退
- 图标网格：支持方向键移动焦点、F2 改名、Delete 删除
- 搜索：Ctrl+K 在本机书签和已打开的标签里搜，也可以切换成 Google、必应、百度等搜索引擎，或自定义带 %s 的地址模板
- 多选批量：Ctrl 加选、Shift 范围选，选中后整批移动或删除
- 自由摆放：可以把图标拖到任意格子，位置记在本机，按文件夹分别保存
- 撤销：Ctrl+Z 最多回退 40 步，覆盖新建、删除、改名、移动、建组和布局调整
- 外观：浅色与深色主题、6 组主题色加自定义取色、5 套渐变壁纸或本地图片、三档图标大小
- 界面语言：中英两套文案，跟随浏览器语言

权限说明

- 书签：读取书签树用于渲染分页和图标，写入用户拖拽、改名、删除的结果。书签是本扩展唯一的数据源
- 图标：从浏览器本地缓存读取网站图标作为书签图标，不单独请求目标网站
- 存储：保存主题、壁纸、布局坐标、搜索源等设置，只存本机
- 标签页：Ctrl+K 搜索时列出当前打开的标签页标题和网址，仅用于本地搜索，不上传

隐私

不收集任何数据，不上传任何内容，没有账号系统，没有分析工具。所有设置存在本机 chrome.storage.local，卸载扩展即清空。隐私政策的完整说明见商店信息里的链接。

已知限制

- 仅支持 Chromium 内核浏览器（Chrome、Edge、Brave）
- 删除书签是真实删除，会同步到账号，操作前有确认框
- 自由摆放的坐标不存在书签字段里，换设备后回到自动排布

反馈

遇到问题或想要某个用法，欢迎在 GitHub 仓库开 issue。
```

## 6. 单一用途说明

```
在新标签页里以图标网格展示浏览器书签，并允许在该页面上直接整理书签（排序、移动、建文件夹、改名、删除），所有改动写回浏览器自带的书签数据。
```

## 7. 权限理由（后台逐项填写）

| 权限 | 填写内容 |
|---|---|
| bookmarks | 用于读取书签树以渲染新标签页的分页和图标，并把用户拖拽、改名、移动、删除的结果写回书签。书签是本扩展唯一的数据源，不使用其他存储保存书签副本。 |
| favicon | 用于从浏览器本地缓存读取网站图标，作为书签图标显示。不单独请求目标网站，不上传任何网址。 |
| storage | 用于在本机保存界面设置（主题、壁纸、图标大小、布局坐标、搜索源选择）。不用于收集或传输数据。 |
| tabs | 用于在弹出的搜索面板里列出当前打开的标签页标题和网址，方便用户切换。仅在用户主动搜索时读取，不上传。 |
